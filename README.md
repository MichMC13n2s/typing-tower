Simple typing game
descripcion: me and my friend [@senorpann-spec] (https://github.com/senorpann-spec) made this simple game, as we learn how to program in python



## Install:

```bash
pip install -r requirements.txt
python typing_tower.py
```

In Arch / CachyOS:

```bash
sudo pacman -S python-pygame
python typing_tower.py
```


Keybinds

F1:restart
F2: Sound off/on
F11: fullscreen
Esc:pause
with click u can choice an enemy
